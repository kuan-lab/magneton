# Session Log — May 27, 2026

## Summary
Added a new top-level `analysis/` module to magneton implementing the per-instance mito morphometrics pipeline from Sager et al. 2026 (19 features per mito, three SA implementations, PCA+UMAP embedding). Wired into the magneton interactive menu as option 4.

## Changes Made

**New File: `analysis/__init__.py`**
- Re-exports `run, run_interactive` from `.main`; mirrors `instance_segmentation/__init__.py`

**New File: `analysis/config.py`**
- `load_config`, `load_global_config_path`, `get_stage_config(cfg, stage)` mapping `discover/instance/features/paths`
- `strip_file_prefix()` helper for `file://` paths

**New File: `analysis/main.py`**
- argparse CLI with `--stage {discover|instance|instance-hpc|reduce|cluster|all-hpc}`
- `run_interactive()` Rich-table sub-menu (7 options + return)
- `_run_all_hpc()` runs discover inline, sbatches array, then sbatches reduce with `--dependency=afterok:<arrayID>`
- Reduce script's `--partition` inherits from `instance_stage.hpc.partition` (not hardcoded)

**New File: `analysis/lib/precomputed_io.py`**
- `VolumeSpecs` dataclass, `get_volume_specs`, `read_full`, `read_bbox`
- All CloudVolume reads use `parallel=1` (py3.13 multiprocessing spawn-vs-fork incompatibility)

**New File: `analysis/lib/surface_area.py`**
- `sa_face_count` — 6-face exposure × face area (nm²)
- `sa_marching_cubes` — pads mask with 1-voxel zero border so `level=0.5` is always crossed
- `sa_sqrt_kernel` — paper-faithful, `sum(sqrt(num_bg_face_neighbors))` over inner border
- `compute_sa(mask, vox_nm, method)` dispatcher; same pattern for 2D `compute_perimeter`

**New File: `analysis/lib/plane_sampling.py`**
- Ported `calc_plane_coords`, `find_cross_section`, `get_center_object` from the paper's `voxel_utils.py`
- `calc_plane_coords` takes optional `center_xyz` — needed because bbox-center plane sampling misses elongated mitos whose mass is far from the bbox geometric center
- `cart_to_spherical` + `orthonormal_basis` helpers

**New File: `analysis/lib/features.py`**
- `compute_all_features(mask, vox_nm, cfg) -> dict[str, float]` returns the 19 features
- `compute_pcs` from local 3×3 covariance via `np.linalg.eigh` (exact, no subsampling — paper uses 1% subsample)
- `compute_symmetry(proj, axis, rounding)` via union-of-reflected-set on integer-quantized PC projections; supports `nearest` (default) or `truncate` (paper)
- `refine_to_tight_bbox` re-crops the mask to its true voxel extent after high-mip discovery's halo
- Cross-section through PC plane uses `find_cross_section(center_xyz=centroid_voxels)`, not bbox center
- `feature_names()` returns stable column order

**New File: `analysis/lib/manifest.py`**
- `make_ranges(n_total, per_task)`, `write_manifest`, `read_manifest_line` for SLURM array sed-pattern

**New File: `analysis/stages/discover_bboxes.py`**
- Reads full mip-N volume, `scipy.ndimage.find_objects`, pads halo at mip-N first then upscales to mip-0
- Writes `<output>/bboxes.parquet`: `seg_id, bbox_x0..z1, mipN_voxel_count`

**New File: `analysis/stages/instance_features.py`**
- Per-task worker: reads bboxes.parquet row range, crops mip-0 per row, masks to seg_id, calls `compute_all_features`, writes `task_<k>.parquet`

**New File: `analysis/stages/instance_features_hpc.py`**
- SLURM array submitter mirroring `merge_apply_hpc.py:_slurm_script`
- Writes per-task `manifest.txt` (each line `start,end` row range) + `submit_slurm.sh` with `#SBATCH --array=0-(N-1)%batch_num`
- Supports optional `qos` field in HPC config (passes `--qos` if set)

**New File: `analysis/stages/reduce_features.py`**
- Concats `stage2_partials/task_*.parquet`, sorts by `seg_id`, writes `morphometrics.parquet`

**New File: `analysis/stages/cluster.py`**
- Stage D: z-scores features (log1p on right-skewed columns), runs PCA (`sklearn`) + UMAP (`umap-learn`)
- Writes `morphometrics_embedded.parquet` (original 21 cols + PCA1/2/3 + UMAP1/2)
- Emits diagnostic plots under `plots/`: `explained_variance.png`, `pca_loadings.png`, `umap_by_volume.png`, `umap_by_sphericity.png`, `umap_by_pca1.png`
