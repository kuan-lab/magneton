## Changes Made

### 1. Modified: `toolkit/tools/downsample_prec.py`

#### Bug Fix: Queue monitoring logic
The original code terminated workers after 60 seconds of no file modifications, even if the queue still had tasks.

**Changes to `run_multiple_workers()`:**
- Added `get_queue_count()` helper to count remaining `.json` tasks
- Activity timer now resets on file modifications OR queue count changes
- Added informative warning when terminating with remaining tasks
- Increased `idle_exit_seconds` default from 60 to 300 seconds (5 minutes)

#### New Feature: Dynamic memory target calculation
Igneous had a hardcoded 3.5GB memory limit, only allowing 3 mips per task batch.

**New functions:**
- `parse_memory_string()` - Parses strings like "32G", "4096M" to bytes
- `calculate_memory_target()` - Calculates optimal memory per task:
  - **SLURM mode**: Detects via `SLURM_JOB_ID`, calculates `(SLURM_MEM_PER_CPU * SLURM_CPUS_PER_TASK / num_workers) * 0.75`
  - **Non-SLURM mode**: Uses 5GB default

### Memory Target Behavior
- Default 3.5GB limits tasks to 3 mip levels at once

- Allows 5+ mips per task batch
