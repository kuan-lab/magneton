# Session Log — September 17, 2026

## Summary
Replaced overlap-vote block stitching in instance segmentation with a graph pipeline (non-overlapping cores + region graph + one global merge), after tracing a dendrite/axon merge error to `select_pairs` unioning two neurons across a 38-voxel membrane strip. The old pipeline is preserved verbatim as "legacy" behind its own CLI entry and config pointer. Also covers 09-14/09-15 work: fib_b/fib_f affinity inference and their downsample/segmentation configs.

## Changes Made

**New File: `instance_segmentation/utils/graph_utils.py`**
- `fragment_id_bump(block_index, core_shape_zyx)` / `bump_ids` — uint64 offsets making per-core fragment ids globally unique with no coordination (uint32 overflows at 48 cores of 768³).
- `write_edges_npz` / `read_edges_dir` / `dedupe_edges(how="max"|"min"|"mean")` — per-core edge lists and duplicate collapse.
- `components_from_edges(u, v, score, contact, threshold, min_contact)` — threshold + contact filter, `scipy.sparse.csgraph.connected_components`, root = smallest fragment id (keeps the LUT idempotent).
- `write_lut_npz` / `read_lut_npz` / `apply_lut` — ids absent from the LUT keep their own id.
- `MergeTree` — LCA over a waterz merge history via per-merge virtual nodes (waterz reuses an input id as the output id, so the history is not a parent forest); `find_merge(u, v)` returns the bottleneck score or `None`.
- `contact_counts(frag_zyx)` — voxel-face contact area per fragment pair, via slice views.

**New File: `instance_segmentation/stages/fragments_stage.py`, `fragments_stage_hpc.py`**
- Pass 1: watershed over core+halo, crop to the core, bump ids, write one global uint64 fragments volume; per-core metadata + `.done`.
- `build_grid(cfg, aff_vol)` — core grid from `block.core`/`block.halo`, optional `block.roi` (chunk-aligned origin).
- `submit_array(...)` — shared SLURM array submitter for the per-core stages; `config_path` override so a stage can run a config other than the root pointer.
- Array concurrency now defaults to `array_len` instead of `1` (a missing `hpc_num` silently serialised arrays).

**New File: `instance_segmentation/stages/edges_stage.py`, `edges_stage_hpc.py`**
- Pass 2: read fragments + affinity over core+halo, relabel locally, run waterz with `return_merge_history` + `return_region_graph`, export `(u, v, score, contact)` per core; logs kept/cross-core edge counts.
- Contact area is measured **before** `agglomerate()` (waterz mutates the fragments array in place).
- Refused merges are exported as `inf`, never as the pre-agglomeration region-graph score.
- Ownership filter (≥1 endpoint owned by this core) + `require_all_fragments` guard.
- `relabel_blocks_hpc(...)` — pass 4 submitter (passes `--lut`).

**New File: `instance_segmentation/stages/global_merge.py`**
- Pass 3: concat edge npz, dedupe, threshold + `min_contact`, connected components → LUT; prints score percentiles and drop counts. Reads no image data.

**New File: `instance_segmentation/stages/relabel_stage.py`**
- Pass 4: apply the LUT per core into `paths.output` (or in place); writes `counts_XXXX.npz` per core alongside `.done`.

**New File: `instance_segmentation/stages/segment_props_stage.py`**
- Pass 5: merge per-core counts into `<output>/segment_properties` + the `info` pointer; `require_all_cores` guard; optional `#debris` tag from an affinity rescan.

**New File: `toolkit/tools/segment_props.py`**
- `write_segment_properties(...)` — shared writer (size labels, `#tiny/#small/#medium/#large`, optional `#debris`); atomic temp+replace so concurrent array tasks cannot truncate the file.
- `segment_props(cfg)` — standalone toolkit tool for any precomputed segmentation.

**New File: `instance_segmentation/tools/run_fragments_shard.py`, `run_edges_shard.py`, `run_relabel_shard.py`**
- SLURM array workers for passes 1, 2, 4.

**New File: `instance_segmentation/tools/trace_merge.py`**
- Traces a legacy merge: final id → union pool → per-edge overlap stats recomputed from the block volumes; `--coord-nm` for 4nm input; IoU-weighted min cut between two points to locate the union(s) actually responsible.
